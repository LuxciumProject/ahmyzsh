# Oh My Zsh custom boundary

`ZSH_CUSTOM` points here so OMZ never treats the entire AhMyZSH repository as
its custom tree. Future custom OMZ plugins or themes may be added using OMZ's
standard `plugins/<name>/` and `themes/` layout.

General AhMyZSH modules do not belong here.
