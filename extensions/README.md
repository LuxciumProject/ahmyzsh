# Postponed extension planes

These directories are architectural placeholders, not active modules. They
prevent future capabilities from leaking into the backbone before their
dependencies and lifecycle are understood.

| Plane | Intended result | Current status |
|---|---|---|
| `path-loader/` | declarative optional path/runtime composition | postponed |
| `tmux/` | validated declarative project sessions | postponed |
| `repl/` | independent Node and Python interactive laboratories | postponed |
| `machines/` | typed Kubuntu/host capabilities and optional modules | postponed |
